About My Todo App

Welcome to my Todo application! This is my first Django project, built while learning Python, Django, databases, and web development.

What can this app do?

A simple task management application with everything needed to manage your daily tasks.

➕

Create Tasks

Add new Todo tasks and keep everything organized in one place.

📋

View Tasks

View all your tasks in a clean and easy-to-read table.

✅

Track Progress

Mark tasks as completed and keep track of what's still pending.

✏️

Edit Tasks

Update your Todo information whenever something changes.

This project is part of my journey into web development. Through this application, I'm learning how Django models, views, URLs, forms, templates, databases, and multiple apps work together.
